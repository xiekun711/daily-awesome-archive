# GitHub Awesome Daily

📅 **每日高质量开源项目归档** — 自动搜索 GitHub 上的优质开源项目，按天归档。

每天 08:00 (北京时间) 自动扫描 GitHub Trending，精选高质量项目并归档到这里。

## 🚀 如何工作

1. 每天 08:00 通过 GitHub API 搜索 5 个领域的高质量项目
2. 自动评分筛选（✨ 推荐等级）
3. 归档到 `data/` 目录
4. 自动推送到 GitHub 仓库
